# API route reference

Generated by `npm run docs:routes` from the running route table (254 routes). Do not edit by hand.

**Conventions**

- Base URL: `{API}/api`. JSON in, JSON out. Successful responses: `{ "success": true, "message": "...", "data": ..., "meta": { page, limit, total, pages } }`.
- Errors: `{ "success": false, "message": "...", "details": [{ "field": "email", "message": "..." }] }` with HTTP 400 / 401 / 402 / 403 / 404 / 409 / 429 / 5xx.
- Authentication: `Authorization: Bearer <accessToken>` (access tokens live 15 minutes; renew with `POST /api/auth/refresh`).
- **Auth** column: "public" needs no token, otherwise a valid access token. **Roles** lists who may call it ("any" = every signed-in role; ownership/enrolment checks are applied inside).
- Pagination: `?page=1&limit=20` (limit is capped at 100).
- Uploaded files are never public (except avatars and course thumbnails): ask `POST /api/files/sign` for a short-lived link first.
- Payment gateway webhooks (`/api/webhooks/*`) are called by Paystack / Flutterwave and are protected by signature verification, not tokens.
